# Path of Idle

A browser idle ARPG combining automatic combat, Path of Exile-style builds/loot/crafting, and gathering and production. Six campaign acts lead into ten themed map tiers. Six main classes choose among twelve ascendancies; Exile is an unlockable challenge class.

## Run

Requires Node 20+.

```sh
npm ci --no-audit --no-fund
npm run dev
npm test
npm run build
```

`dev` starts Vite; `build` generates the player wiki, typechecks and builds for Cloudflare. Account features require Supabase values in `.env.local`; see the setup runbook. Dev exposes `window.game` for inspection.

## Source layout

`src/engine` contains simulation; `src/data` contains content; `src/platform` handles accounts/storage/services; `src/ui` contains React screens; `src/game.ts` coordinates them. `tests` covers engine/platform behavior and server market SQL. `scripts` contains wiki/art/unique generation, simulations and deployment.
