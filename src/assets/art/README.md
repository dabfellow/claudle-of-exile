# Game art

1. Open docs/ART_PROMPTS.md. Each grey box is a complete prompt: copy it, paste it into ChatGPT, send.
2. Save the image with the file name in its heading (`trader.png`, `currency_1.png`, …) and drop it anywhere in this folder.
3. Run `npm run art`: it resizes/compresses each one to `.webp`, cuts sprite sheets into their 9 icons, deletes the originals and tells you what's next.

Anything missing falls back to the built-in placeholder.
