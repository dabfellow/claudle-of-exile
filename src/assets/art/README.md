# Game art

1. Generate images with the prompts in docs/ART_PROMPTS.md and save them with the listed file names.
2. Drop them into the matching folder here (`currency/chaos.png`), or loose in this folder if the name is unique.
3. Run `npm run art`: it resizes/compresses each one to `.webp`, deletes the original and reports what's missing.

Anything missing falls back to the built-in placeholder.
